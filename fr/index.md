# Code de parrainage Fomo DEAL (2026) : lien fomo.family/r/deal, 10 % de remise + cashback sur les frais

Pour profiter du code de parrainage Fomo DEAL, ouvrez le lien d'invitation fomo.family/r/deal avant de créer votre compte. L'offre s'appelle 10% Off + Fee Cashback (10 % de remise + cashback sur les frais). La remise de 10 % vient de Fomo, qui ne verse en revanche aucun cashback : c'est le détenteur du code DEAL qui vous reverse 12,5 % de vos frais Fomo, en USDC.

| Code de parrainage | Remise | Frais spot effectifs | Pour qui |
|---|---|---|---|
| DEAL | 10 % sur les frais de trading | 0,45 % (au lieu de 0,50 %) | Nouveaux comptes, à l'inscription |

C'est la remise de parrainage standard de Fomo, la même pour tous les codes. DEAL ajoute un cashback de 12,5 % des frais, versé par le titulaire du code.

*Informations relevées dans le centre d'aide de Fomo le 20 octobre 2026.*

## Ce que donne Fomo, ce qu'ajoute le détenteur du code DEAL

**Côté Fomo.** Avec un code de parrainage, un nouvel inscrit paie 10 % de frais en moins sur chaque transaction : 0,45 % au lieu de 0,50 %. Selon le centre d'aide, c'est le seul avantage accordé par Fomo : ni cashback, ni prime d'inscription en argent, ni remise plus forte pour un code.

**Côté détenteur du code DEAL.** Fomo reverse au propriétaire d'un code 25 % des frais de trading payés par les personnes inscrites avec ce code. Cette part sort des frais que vous payez de toute façon : rien ne s'ajoute à votre facture. Le détenteur du code DEAL vous en rend la moitié, soit 12,5 % de vos frais Fomo, versés en USDC.

**Ce n'est pas une remise plus grosse.** Chez Fomo, tous les codes donnent les mêmes 10 %. Le cashback est un paiement à part, en USDC, pris sur la part de parrainage du détenteur du code.

## Utiliser DEAL au moment de l'inscription

1. Ouvrez fomo.family/r/deal avant de créer un compte.
2. Inscrivez-vous dans l'application iOS ou Android, ou sur fomo.family dans le navigateur, avec un identifiant Apple ou un compte Google.
3. Le code s'applique sur l'écran d'inscription. Si un code est demandé, tapez DEAL.
4. Avant votre première transaction, regardez le récapitulatif des frais : il doit indiquer 0,45 %. Sur Solana, une très petite transaction peut afficher un minimum fixe à la place.

Après l'inscription, aucun champ ne permet d'ajouter un code. Lien utilisé, mais aucun parrain enregistré ? Écrivez au support depuis l'application (Profile > Settings > Help and Support > Contact Support) et demandez à être rattaché au code DEAL. Un parrain déjà enregistré ne peut être ni supprimé ni changé.

## Frais de réseau

Fomo paie le gas uniquement sur Solana, avec les frais de priorité et le rent des tokens. Sur Base, BNB Chain, Monad, Ethereum, Robinhood Chain et Arc, les frais de réseau s'ajoutent aux frais Fomo et figurent dans le devis.

## Perps

Sur les perps, Fomo prélève 0,05 % par transaction, à l'ouverture comme à la clôture. Fomo ne précise pas si ce taux porte sur la marge ou la position entière. S'y ajoutent les frais d'Hyperliquid, sur toute la position avec effet de levier, et le funding horaire, un coût à part. Fomo n'indique pas si la remise de 10 % vaut aussi pour les perps. Le cashback DEAL, lui, inclut les frais Fomo des perps. Les perps sont fermés aux « U.S. Persons » : citoyens ou résidents des États-Unis et toute personne qui s'y trouve. Un VPN n'y change rien.
