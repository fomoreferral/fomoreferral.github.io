# Fomo Cashback Code DEAL: How the 12.5% Fee Cashback Works, With the Math (2026)

The Fomo cashback code is DEAL: sign up through fomo.family/r/deal and you get 10% Off + Fee Cashback, which means a lower Fomo fee plus 12.5% of the Fomo fees you pay returned to you in USDC.

Keep two facts apart. Fomo runs no cashback program of its own; the only referral benefit it gives a new user is the 10% fee discount. The cashback on DEAL is a separate offer from the DEAL code owner, who returns half of the 25% referral share that Fomo pays them.

Last checked: 20 October 2026.

## The formula

Cashback = Fomo fee you paid × 12.5%

With any referral code, Fomo's standard spot fee is 0.45% of the trade instead of 0.50%. On a standard spot trade with DEAL that gives:

- Fomo fee = trade size × 0.45%
- Cashback = trade size × 0.45% × 12.5% = trade size × 0.05625%
- Your fee after cashback = trade size × 0.39375%

Network fees, Hyperliquid's own perps fee and token contract fees are not Fomo fees, so they stay out of the calculation.

## Questions

**Does Fomo pay the DEAL cashback?**
No. Fomo pays no cashback for any code. The DEAL cashback comes from the DEAL code owner.

**Does the cashback replace the 10% discount?**
No. The 10% is Fomo's and stays as it is. The cashback comes on top of it.

**Can an existing account get the cashback?**
Only an account that was created with DEAL. Fomo has no way to add a code after sign-up, and a recorded referrer can't be changed.
