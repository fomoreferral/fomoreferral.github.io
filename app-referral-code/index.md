# Fomo App Referral Code: DEAL for iPhone, Android and Web (2026)

The Fomo app referral code is **DEAL**. It works the same way in the Fomo crypto app on iPhone and Android and in the web app at fomo.family, and it gives 10% Off + Fee Cashback: Fomo's standard trading fee drops from 0.50% to 0.45% per trade, and the DEAL code owner returns 12.5% of the Fomo fees you pay, in USDC.

Invite link: [fomo.family/r/deal](https://fomo.family/r/deal). Code DEAL is verified working (November 2026). Facts checked against Fomo's help center on 22 November 2026.

## Where the Fomo app asks for a referral code

| Where you are | What happens | What to do |
|---|---|---|
| First sign-in on iPhone or Android | If no referrer is recorded yet, the app asks for a code | Type DEAL |
| Signed up already, no trade made | The mobile app asks for a code at log-in, as long as no referrer is recorded | Type DEAL |
| Web app at fomo.family | A code from a fomo.family/r/ link applies on its own after login | Open fomo.family/r/deal, then log in |
| After your first trade | A code can no longer be added | Nothing to do: the account stays as it is |

Fomo's rule in one line: a referral code can be applied until your first trade, and a referrer that is already recorded can't be removed or changed.

## Steps for each device

**iPhone (App Store)**

1. Open fomo.family/r/deal in Safari on the iPhone you'll trade on.
2. Install Fomo from the App Store.
3. Tap Sign in with Apple or Sign in with Google.
4. When the app asks for a referral code, type DEAL.

**Android (Google Play)**

1. Open fomo.family/r/deal in the phone's browser.
2. Install Fomo from Google Play.
3. Tap Sign in with Google or Sign in with Apple.
4. When the app asks for a referral code, type DEAL.

**Web app (fomo.family)**

1. Open fomo.family/r/deal in your browser.
2. Choose Continue with Apple or Continue with Google.
3. The code from the link applies on its own after login.

## What DEAL changes in the Fomo crypto app

| | No code | Code DEAL |
|---|---|---|
| Fomo's standard trading fee | 0.50% per trade | 0.45% per trade |
| Fee cashback | None | 12.5% of the Fomo fees you pay, in USDC, from the DEAL code owner |
| Extra cost to you | - | None: Fomo's referral share comes out of the fee you already pay |

The discount applies to Fomo's percentage rate. These stay the same with any code: the 0.05% rate on lowered-fee tokens, the fixed fees on small Solana trades, and network fees on other networks. On Solana, Fomo covers the network gas itself.

## How to check the code worked

Before your first trade, open a trade preview for a regular token of 190 USDC or more and look at Fomo's fee line: it should read 0.45%, not 0.50%. Smaller Solana trades use fixed fees, so they don't show the discount.

Signed up through the DEAL link but the preview shows 0.50%? In the app, open the Portfolio tab, tap the gear icon, then Help and Support, tap Contact support and ask to be attached to DEAL. This works only while no referrer is recorded on the account.
